# Лапта — народная игра России

Одностраничный сайт о лапте: история, правила, фотогалерея, видео и проверочный тест.

## Что лежит в папке

- `index.html` — страница (в корне!)
- `style.css` — все стили; шрифт `Russo One` вшит внутрь файла, поэтому он работает и с сервера, и при открытии файла двойным щелчком
- `script.js` — тест из пяти вопросов и плавное появление блоков
- `images/` — фотографии в `webp`, превью для соцсетей `preview.jpg`, иконки
- `404.html` — страница для несуществующих адресов
- `robots.txt`, `.nojekyll` — служебные файлы для GitHub Pages

Внешних сервисов нет: ни Google Fonts, ни счётчиков, ни CDN — сайт полностью работает
из папки, в том числе по двойному щелчку по `index.html` и без интернета.

## Как выложить на GitHub Pages

1. Создайте публичный репозиторий (например `lapta`).
2. **Add file → Upload files** и перетащите **содержимое** этой папки так, чтобы
   `index.html` оказался в корне репозитория (не внутри вложенной папки).
3. **Commit changes**.
4. **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
5. Через минуту сайт откроется по адресу `https://ЛОГИН.github.io/lapta/`.

## Что стоит доделать вручную

- В `index.html` есть теги `og:image` и `twitter:image` с относительным путём
  `images/preview.jpg`. После публикации замените его на полный адрес вида
  `https://ЛОГИН.github.io/lapta/images/preview.jpg`, иначе превью не покажется в соцсетях.
- Если появится свой домён, добавьте `sitemap.xml` с полным адресом страницы
  и строку `Sitemap:` в `robots.txt` — сейчас домена нет, поэтому файла нет.
- Видео в разделе «Видео о лапте» открывается на RUTUBE в новой вкладке:
  для просмотра нужен интернет.
- Снимки в фотогалерее взяты из исходного файла, авторство и лицензии в нём не указаны.
  Перед публичным использованием стоит подтвердить права на фотографии.
